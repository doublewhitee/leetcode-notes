# 13. 罗马数字转整数

## 题目

罗马数字包含以下七种字符: `I`， `V`， `X`， `L`，`C`，`D` 和 `M`。

| **符号**  | I    | V    | X    | L    | C     | D     | M     |
| ---       | ---  | ---  | ---  | ---  | ---   | ---   | ---   |
| **值**    | 1    | 5    | 10   | 50   | 100   | 500   | 1000  |

例如， 罗马数字 `2` 写做 `II` ，即为两个并列的 1 。`12` 写做 `XII` ，即为 `X` + `II` 。 `27` 写做  `XXVII`, 即为 `XX` + `V` + `II` 。

通常情况下，罗马数字中小的数字在大的数字的右边。但也存在特例，例如 4 不写做 `IIII`，而是 `IV`。数字 1 在数字 5 的左边，所表示的数等于大数 5 减小数 1 得到的数值 4 。同样地，数字 9 表示为 `IX`。这个特殊的规则只适用于以下六种情况：

+ `I` 可以放在 `V` (5) 和 `X` (10) 的左边，来表示 4 和 9。
+ `X` 可以放在 `L` (50) 和 `C` (100) 的左边，来表示 40 和 90。
+ `C` 可以放在 `D` (500) 和 `M` (1000) 的左边，来表示 400 和 900。

给定一个罗马数字，将其转换成整数。

**示例 1：**

> 输入: s = "III"
> 输出: 3

**示例 2：**

> 输入: s = "IV"
> 输出: 4

**示例 3：**

> 输入: s = "IX"
> 输出: 9

**示例 4：**

> 输入: s = "LVIII"
> 输出: 58
> 解释: L = 50, V= 5, III = 3.

**示例 5：**

> 输入: s = "MCMXCIV"
> 输出: 1994
> 解释: M = 1000, CM = 900, XC = 90, IV = 4.

## 方法 1：模拟

遍历过程中，会遇到两种情况：

1. 左边的罗马数字大于等于右边的罗马数字：这是通常的情况，此时只要将每个字符视作为单独的值去计算即可。
2. 左边的罗马数字小于右边的罗马数字：此时需要将右边的值减去左边的值去计算。

```javascript
var romanToInt = function(s) {
  const map = {
    I: 1,
    V: 5,
    X: 10,
    L: 50,
    C: 100,
    D: 500,
    M: 1000,
  }

  let res = 0;
  let index = 0;
  // 遍历
  while (index < s.length) {
    if (s[index] && s[index + 1] && map[s[index]] < map[s[index + 1]]) {
      // 左边的罗马数字小于右边的罗马数字
      res += map[s[index + 1]] - map[s[index]];
      index += 2;
    } else {
      // 左边的罗马数字大于等于右边的罗马数字
      res += map[s[index]];
      index ++;
    }
  }
  return res;
};
```
