# 22. 括号生成

## 题目

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且**有效的**括号组合。

**示例 1：**

> 输入：n = 3
> 输出：["((()))","(()())","(())()","()(())","()()()"]

**示例 2：**

> 输入：n = 1
> 输出：["()"]

**示例 3：**

> 输入：n = 2
> 输出：["()()","(())"]

**提示：**

- `1 <= n <= 8`

## 方法 1：回溯（深度优先搜索）

**思路：** 一个长度为 `2n` 的括号序列里，左括号和右括号各 `n` 个。我们按位置依次决定每个位置放左括号还是右括号，过程中维护两个计数器 `leftCnt`（已放的左括号数）和 `rightCnt`（已放的右括号数）。为了保证生成的序列始终合法，每一步要满足两个约束：

1. 左括号数不能超过 `n`：`leftCnt < n` 时才能放左括号。
2. 右括号数不能超过左括号数：`rightCnt < leftCnt` 时才能放右括号（否则会出现 `))((` 这类不合法前缀）。

当 `leftCnt === n` 且 `rightCnt === n` 时，说明已经放完 `2n` 个括号，得到一个合法组合。

**关键点：**

1. 用一个字符串或数组 `path` 记录当前正在构建的前缀
2. 终止条件：`path.length === 2 * n`，把当前组合加入结果集
3. 选择左括号分支：当 `leftCnt < n` 时，把 `(` 放入 `path`，递归，再回溯弹出
4. 选择右括号分支：当 `rightCnt < leftCnt` 时，把 `)` 放入 `path`，递归，再回溯弹出
5. 这两个条件天然把 `))((`、`(()` 之类的非法前缀挡在递归之外，不需要额外判断

```javascript
var generateParenthesis = function(n) {
  const res = [];

  // path：当前构建中的前缀
  // leftCnt / rightCnt：已经使用的左/右括号数量
  const backtrack = (path, leftCnt, rightCnt) => {
    // 已经放了 2n 个括号，得到一个合法组合
    if (path.length === 2 * n) {
      res.push(path.join(''));
      return;
    }
    // 还能放左括号
    if (leftCnt < n) {
      path.push('(');
      backtrack(path, leftCnt + 1, rightCnt);
      path.pop(); // 回溯
    }
    // 还能放右括号（且不会破坏合法性）
    if (rightCnt < leftCnt) {
      path.push(')');
      backtrack(path, leftCnt, rightCnt + 1);
      path.pop(); // 回溯
    }
  };

  backtrack([], 0, 0);
  return res;
};
```

时间复杂度：**`O(Cₙ · n)`**，其中 `Cₙ` 是第 `n` 个卡特兰数（合法括号序列的总数）。每个合法序列长度都是 `2n`，拼接结果需要 `O(n)` 时间。
空间复杂度：**`O(n)`**，递归栈深度和 `path` 的长度都是 `O(n)`；不计存放结果的 `O(Cₙ · n)` 空间。

## 方法 2：动态规划（自底向上）

**思路：** 观察任意一个合法的 n 对括号序列，把「最左边那个左括号」和「跟它配对的那个右括号」圈出来，整个序列就被自然切成三段：

内部 inner 和外侧 rest 各自也都是合法的括号序列（可以为空）。设 inner 有 k 对括号，那么 rest 就一定有 n - 1 - k 对括号（因为整个序列除了「最左那对外层括号」外总共还剩 n - 1 对）。k 的取值范围是 `[0, n - 1]`：inner 和 rest 都必须是非负对数，所以 `k ≥ 0` 且 `n - 1 - k ≥ 0`，即 `k ≤ n - 1`。

```plaintext
(  + 内部 inner  +  )  +  外侧 rest
```

以 n = 3 的 5 个合法序列为例，每个都能这样拆：

| 序列 | 拆分（k） |
| --- | --- |
| `((()))` | `(` + `(())` + `)` + `""`（k = 2） |
| `(()())` | `(` + `()()` + `)` + `""`（k = 2） |
| `(())()` | `(` + `()` + `)` + `()`（k = 1） |
| `()(())` | `(` + `""` + `)` + `(())`（k = 0） |
| `()()` | `(` + `""` + `)` + `()`（k = 0） |

所以 n 对括号的所有合法序列，可以从更小的子问题**拼装**出来：

```plaintext
dp[0] = [""]
dp[i] = "(" + inner + ")" + rest，其中 inner ∈ dp[k]，rest ∈ dp[i-1-k]，k ∈ [0, i-1]
```

这个递推式正是卡特兰数的递推 `Cₙ = Σ Cₖ · Cₙ₋₁₋ₖ`（n ≥ 1）。

**关键点：**

1. `dp[i]` 表示 i 对括号的所有合法组合数组；`dp[0] = [""]` 是基础情况（0 对括号唯一合法序列是空串）
2. 外层循环 `i` 从 `1` 到 `n`，逐层构造 `dp[i]`
3. 内层循环 `k` 从 `0` 到 `i - 1`，枚举「最左那一对括号」内部有多少对
4. 对每个 k，把 `dp[k]` 和 `dp[i-1-k]` 做笛卡尔积，每个组合外面套 `(` 和 `)`，塞入 `dp[i]`
5. 最终返回 `dp[n]`

```javascript
var generateParenthesis = function(n) {
  // dp[i] = i 对括号的所有合法组合
  const dp = [['']]; // dp[0] = ['']

  for (let i = 1; i <= n; i++) {
    dp[i] = [];
    // 枚举「最左那一对括号」内部有 k 对，则外侧剩余 i-1-k 对
    for (let k = 0; k < i; k++) {
      for (const inner of dp[k]) {
        for (const rest of dp[i - 1 - k]) {
          dp[i].push('(' + inner + ')' + rest);
        }
      }
    }
  }

  return dp[n];
};
```

时间复杂度：**`O(Cₙ · n)`**，与方法 1 相同。每个 `dp[i]` 要遍历自身所有合法序列并拼接，序列长度 `2i`，所以是 `O(Cₙ · n)`。
空间复杂度：**`O(Cₙ · n)`**，用于存储 `dp[0..n]` 全部子问题的结果（结果主导）。如果只保留 `dp[i-1]` 和 `dp[i]` 两层可以降低常数，但仍是结果主导；想真正降到 `O(n)` 需要换成迭代器式的惰性构造。

> 两种方法时间复杂度相同，差异在**思考角度**：方法 1 是「按字符逐位构造 + 合法性剪枝」，贴近回溯模板；方法 2 是「找出括号序列的递推结构 + 自底向上拼装」，贴近动态规划的标准范式。面试里通常优先写方法 1（更直接、不需要事先看出递推式），方法 2 更适合作为「为什么答案是卡特兰数」的数学解释。
