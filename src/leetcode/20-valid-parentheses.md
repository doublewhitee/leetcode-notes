# 20. 有效的括号

## 题目

给定一个只包括 `(`，`)`，`{`，`}`，`[`，`]` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

**示例 1：**

> 输入：s = "()"
> 输出：true

**示例 2：**

> 输入：s = "()[]{}"
> 输出：true

**示例 3：**

> 输入：s = "(]"
> 输出：false

**示例 4：**

> 输入：s = "([)]"
> 输出：false

**示例 5：**

> 输入：s = "{[]}"
> 输出：true

**提示：**

- `1 <= s.length <= 10⁴`
- `s` 仅由括号 `()[]{}` 组成

## 方法 1：栈

**思路：** 栈的经典应用。利用栈的「后进先出」特性，依次处理字符：遇到左括号就入栈，遇到右括号就把栈顶元素取出与之匹配。如果不匹配直接返回 `false`。最后栈为空则说明全部匹配成功。

**关键点：**

1. 使用数组模拟栈，`push` 入栈、`pop` 出栈
2. 遇到左括号时，把对应的右括号入栈（这样匹配时只需判断 `pop` 出来的字符是否等于当前右括号）
3. 遇到右括号时，如果栈为空，说明没有匹配的左括号，直接返回 `false`
4. 遍历结束后，如果栈不为空，说明有未匹配的左括号，返回 `false`；否则返回 `true`
5. 奇数长度的字符串一定无效，可以提前返回（剪枝）

```javascript
var isValid = function(s) {
  // 奇数长度一定不匹配，提前剪枝
  if (s.length % 2 === 1) return false;

  const stack = [];
  // 左括号到右括号的映射
  const openToClose = {
    '(': ')',
    '[': ']',
    '{': '}'
  };

  for (const char of s) {
    if (openToClose[char] !== undefined) {
      // 左括号：把对应的右括号入栈
      stack.push(openToClose[char]);
    } else {
      // 右括号：栈为空或栈顶不匹配则无效
      if (stack.length === 0 || stack.pop() !== char) {
        return false;
      }
    }
  }

  // 栈为空表示全部匹配成功
  return stack.length === 0;
};
```

时间复杂度：**`O(n)`**，其中 `n` 是字符串长度。每个字符最多入栈和出栈一次。
空间复杂度：**`O(n)`**，最坏情况下所有字符都是左括号，栈需要保存全部元素。

> **写法变体：** 上面把左括号对应的右括号预先入栈，比较时直接 `===`。也可以改成"入栈的是左括号、哈希表记录右括号到左括号的反向映射"，思路完全一致，仅是查表方向不同，两种写法性能没有差别，按阅读习惯选用即可。
